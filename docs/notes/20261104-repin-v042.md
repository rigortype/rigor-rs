## 2. Raw bump: 4 fixture FPs, 9,334 sweep FPs

- **G1 (#1683):** top-level calls to `main`'s private singleton methods are no longer
  `call.unresolved-toplevel`. The allow-list is the `RBS::Unnamed::TopLevelSelfClass` methods
  plus `ruby2_keywords`. It covers dependabot's 3,613 FPs, which are RSpec `include(...)`
  matchers and `private` inside top-level blocks. It also covers mail's 28, Ruby's 2 and
  haml's 1.
- **G2 (#1706):** a direct top-level `include M` from any analysed file mixes `M` into
  `Object`. When `M` cannot be resolved, every bare top-level call in the project is silent.
  This accounts for concurrent-ruby's 5,689 FPs (`include Concurrent` in `examples/`).
  - Not counted: an `include` in a `def`, a block or an `if`; `send(:include)`; `extend`; and
    `RSpec.configure { |c| c.include M }`.
  - An unresolvable include silences BARE calls only. The first cut silenced receiver calls
    too, which lost 9 `Benchmark.ips` rows.
- **G3 (#1798):** a call with an ambiguous `Dynamic` argument joins every reachable overload.
  As a result `rand(Dynamic | X)` no longer pins to `Integer`, which reverses a brief claim
  made at e59b7b89. This produced the 4 fixture FPs (99 §13, 105 v6).

## 4. Lessons

- A MATCHED collapse (concurrent-ruby 5,699 → 10) passes a 0-FP sweep whether or not the
  port over-declines. Check it the way the implementer did: diff the v0.4.1 reference against
  the v0.4.2 reference per corpus, then confirm every port row is a v0.4.1 reference row and
  every lost row is a reference retraction.
- A plain sweep measures neither the require-gated vendored sig nor its absence. The prime
  rows came only from the fragment probe.
