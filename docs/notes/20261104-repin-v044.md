# Upstream re-pin `v0.4.3 → v0.4.4` (2026-11-04)

**Pin `v0.4.3` → `v0.4.4` (`c9f6388d`, 2026-10-16)**, 248 commits. Issue #470, PR #471.
This is step five of the tag-by-tag walk to `v0.4.7`; the previous step is in
[v0.4.3](20261104-repin-v043.md).

## 1. What moved

`core_overlay/ostruct.rbs` is new. Upstream loads it unconditionally, so it is vendored.
Gem sigs, the plugin sig, capability roles, effects, the unbuildable table and the
conformance set are all exact. Snapshots 25 and 81 were regenerated.

## 2. Raw bump

0 fixture FPs and 0 sweep FPs, and MATCHED is the same on every corpus. All five families
came from the fragment probe; neither gate sees them.

## 3. Families (all ported)

| family | upstream | port change |
|---|---|---|
| A | #1456, #1982 | `CORE_OVERLAY_OPEN_RECEIVERS` (`OpenStruct`, bare name). `undefined-method` declines on the instance and singleton sides and on union arms, and `raise-non-exception` answers unknown. `argument-type-mismatch` trusts only a signature that OpenStruct declares itself. |
| B | #1819, #1911, #1633 | `private def` / `protected def` record the wrapped def at the call's visibility. `self.private`, `send(:private)` and `private %i[..]` count. The direct table is last-write-wins per name, and `attr_*` only re-marks a recorded name. The census contests splat calls (`private(*names)`) with a wildcard slot. |
| C | #1484, #1961 | A `case` the evaluator does not enter widens each local that a `when` condition writes, to `Dynamic[top]`. A `case` counts as entered when it is a statement or the value of a statement's local write; any other value position is not entered. |
| D | #1948 | `disable: [all]` now covers `pre-eval.*`, which reverses the v0.4.3 F4 port. |
| E | #1953 | Plugin rows answer to `plugin.<id>` and `plugin.<id>.<rule>`, but never to a bare id or `all`. `ConfigAudit.disable_token_warning` is ported for stderr. |

The review found one FP that B introduced. Anchoring on wrapped defs exposed the per-body
table's blindness to a same-file reopening (`class S; public :foo; end`). The port now declines
when another body of the class records the method or runs a visibility modifier. The parent-side
twin is filed as #473.

Pre-existing port FPs fixed along the way:
- The first-write-wins visibility table fired on `def foo; def foo; private :foo`, and the
  bare-`private` form of the reopening above fired too.
- The rule catalogue lacked `global.*`, `call.deprecated-ruby2-keywords` and
  `rbs.contradicting-signature`, so a `# rigor:disable` naming any of them raised
  `suppression.unknown-rule`.

**Result:** 0 FP / 9,441 files / 678 gaps. MATCHED is identical to v0.4.3 and to the raw
bump on every corpus. The gap moves are all on the reference side: gitlab +1, mail +3,
concurrent-ruby −18.

**Declined, all on the safe side:**
- The message drift in #1919/#1970 needs statement-form subjectless `case` narrowing.
- A value-position `case` that the reference does enter, such as `x = (case …)` nested in
  another expression, now declines.
- Visibility merging across reopenings and files is still first-write-wins.

Pre-existing gaps are filed as #472: `pre_eval` monkey-patches, the sig-gen stderr summary,
and literal display inside defs.

## 4. Lessons

- A raw bump at 0 FP with MATCHED unchanged can still carry five families. Every one of
  them came from the fragment probe.
- A reversal (D undoes v0.4.3's F4) is routine on a tag walk. The unit tests that pinned
  the old semantics have to move with it.
