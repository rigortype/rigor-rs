# Issue #357 — modifier `rescue` carriers no longer leak `when`-condition writes

PR #367, merged `b1680fd` (head `b9f9998`). One adversarial round, Approved.

## What landed

A rescue modifier wraps its operand in `Statements{Recovered}` — the `case`
inside never lowers to `Node::Case`/`Node::When`, so #341's
`unevaluated_case_clause_spans` couldn't see the `when`-condition extent and
the recovered write replayed into `local_reach`/`toplevel_rebinds`/
`collect_flow_writes`/`bind_statement` as an ordinary write.

- `Builder` records `blocked_spans`/`blocked_iterative_spans` from
  `Recovered::blocked` children at `lower_recovered`; `LoweredAst` bundles the
  four carrier tables into `Box<CarrierSpans>` (`in_blocked_carrier` /
  `in_iterative_blocked_carrier`) — boxing dodged `large_enum_variant`.
- `reach.rs`: `local_reach`, `ivar_reach`/`cvar_reach` (non-`def`),
  `latest_definite_assignment`, `definitely_assigns` all exclude blocked
  extents.
- `flow_eval.bind_statement` early-returns inside blocked extents;
  `flow_writes` drops blocked writes except scan-visible mutations under
  iterated bodies (#312) and evaluated compound attr writes (#343).
- `visit_case_arms` all-dead fallback (`when … then raise else raise`) marks
  conditions `blocked` while bodies still join — verified: ref binds dead-arm
  body writes too.
- Bonus kills: `(c && (q = 1; raise)) rescue nil`, folded-`if` arms under the
  modifier, `super(h.push(1))` widening — all now silent.

## Measured

~45-probe review: all issue rows silent; over-exclusion clean both directions
(the modifier's own write still binds, prior bindings preserved, `for`-index /
mutation carve-outs unchanged); #356's `loop_body_local_writes` gap unchanged
(neither fixed nor worsened). 0 FP sweep.

## Residual

- **#368** — same leak family outside `Recovered` carriers: dead
  clause-rescue arms, folded `if`-arm writes, block/lambda bodies under rescue
  modifiers, and dead-body `for nil` pruning (surfaced by this fix).
