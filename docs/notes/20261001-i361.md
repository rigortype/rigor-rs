# Issue #361 — `OperandEffects.any?` gate in the `evaluated` decision

PR #369, merged `3eb52e9` (head `1f8cd3e`). One adversarial round, Approved.

## What landed

#343's `AttrWrite.evaluated` marked every write inside a typed operand as
un-evaluated — but the reference's `thread_operand`
(`statement_evaluator.rb:2509-2535`) evaluates an operand iff
`OperandEffects.any?(node)` (`operand_effects.rb:70-89`). A compound attr
write carrying an outliving effect must still land its widening:

```ruby
h = {a:1}; puts(*[h[:a] ||= "s"])
puts(h.default ||= (y = 1))   # operand contains an outliving local write
h[:a].frobnicate             # ref: silent | was port FP
```

- New `rigor-parse/src/ast/operand_effects.rs` (~600 lines): verbatim port of
  `effect?` (LOCAL_WRITE_NODES, OUTLIVING_WRITE_NODES, `depth >= nesting`
  across closures, retargetable `next`/`break`, SHAPE_MUTATORS outliving
  receivers via `element_read_path`/`ReceiverAlias`) + `operand_mode` =
  `thread_operand`'s Dead/Gate/Eval dispatch (HANDLERS census verbatim,
  `OPERAND_CONTAINERS`/`OPERAND_SEQUENCES` verbatim).
- New `dead_operand` mark for typed-but-never-evaluated positions (`return`
  operands, `in` patterns, index-write receiver/indices, attr-write
  receiver+value); `lower_typed_operand` gates every operand element.
- `evaluated` = `dead == 0 && closure == 0 && suppressed == 0 &&
  (typed == 0 || OperandEffects.any?(node))`.
- `SHAPE_MUTATORS`/`is_shape_mutator` moved to `rigor-parse/mutators.rs`.

## Measured

Review: ~60 probes, zero port-only diagnostics; the per-element Gate vs
Eval-whole asymmetry verified (`[h.x ||= 0, (y=1)]` vs `(h.x ||= 0) && (y=1)`
— matches ref exactly). Sweep 0 FP / 818 gaps. `merge-tree` clean vs master.
