## 2. Raw bump: 8 fixture FPs + 9 sweep FPs, two families

- **F1: `5496acd6` (#1021 / PR #1022), `imprecise_arg?`.** An argument typed
  `Dynamic[top] | X` now declines overload selection the way a bare `Dynamic[top]` does. That
  retracts fixtures 99 (a7/a20/q3) and 105 (r5/z6/z10/z7/i12). The port replaces the boolean
  "reference-untyped root" test with a `Reach { untyped, precise, opaque }` analysis. A
  parameter's untyped value reaches a read unless a DEFINITE assignment cuts it off
  (`if`/`else` or `case`/`else` where every arm assigns or returns). Ivars, cvars and gvars
  decline on ANY untyped write. The generic RBS gate uses the same reach test.
  - **What the brief got wrong:** `rand` keeps firing through a union, because the reference
    still pins `rand(Dynamic | "x")` to `Integer`.
  - **Also missed:** an `if`'s `else` lowers to a clause-less `BeginRescue`.
  - **Result:** 11 independent audit probes had the same fire set on both engines.
- **F2: `ee33407e` + `f918c6f0` (PR #1135).** `call.unresolved-toplevel` declines every
  receiverless call inside the block of `class_eval`, `module_eval`, `class_exec`,
  `module_exec`, `instance_eval` or `instance_exec`, whatever the receiver. That covers the 9
  sweep FPs, in rspec's `minitest_integration.rb` inside mail's `vendor/bundle`. The port adds
  `block_span` on `Node::Call` and `receiver_eval_block_spans`.
  - **Coupled companion, deliberately NOT ported:** `fb781023`, from the same PR, moves defs
    inside those blocks off the toplevel def table. That is what makes the reference fire
    **3,002** new `expect` / `to` rows on mail. The port still holds the two phantom toplevel
    entries and stays silent, which is the safe direction.
  - Porting `fb781023` WITHOUT the carve-out would recreate the one-day upstream FP window.
    See #141.

#999/#1010), #144 (ADR-114 ancestor dispatch), and #145 (grab bag).

Not probed, and not claimable: the three `rbs-inline` fragments (#1005/#1018/#1023) need the
`rbs-inline` gem, which is not installed here. Without it the reference answers with an
