PR #289 (merged `a7310a8`). Ports `Rigor::Environment::RbsLoader`'s project-`sig/`
reading: `use Foo::Impl as B`, `use Foo::Impl`, `use Foo::*` (wildcard expands to
known direct children via `UseMap::build_map` semantics), the first-line
`# resolve-type-names:` magic comment (only exact `false` disables; spaceless and
non-first-line variants do not), and `stub_missing_referenced_types` — `_X` →
empty interface, `Cap` → class, `lower` → `type x = untyped`, namespace prefixes

identity but read `Dynamic[top]` downstream — never witnessable as "proven".

## Resolution model

Project signatures keep full-fidelity written names per file context
(`FileSigCtx`); the bundled path's leaf-only storage keeps `resolve_leaf_unique`.
Written refs (member returns, superclass/include/self-type args) and module
self-types resolve by one head-first walk over `type_names` (`has_type_name? ||
aliased_name?` — both sets live there): innermost scope outward, first binding
wins, `absolute!` root fallback when a head or tail is absent. A bound
class/module-alias segment is unmodelled — the reference normalizes through an
`old_name` target the index never records — so it declines rather than skipping
to an outer namesake. Self-types additionally classify the bound name: buildable
iff `qualified` (class/module) or a `_`-leaf interface; a type alias or missing
name fails the build the same way the reference's `build_instance` raises.
