## 3. Families (all ported)

Two read-only investigators did the work. One recorded every `analyze()` input from 42
v0.4.7 spec files as 1,223 fragments; the other probed the rest by hand. Their findings went
to three implementers in parallel worktrees, merged before review.

**Review fixes:** the adversarial review found three problems, all fixed in the PR.
- A `core_root:` core the reference cannot build: the port now declines per class (an
  unresolved superclass or mixin, an undeclared interface, an overload with no original, a
  duplicated member, self-type recursion), or wholesale when the core does not close over itself.
- LSP, mcp, `doctor` and `coverage` ignored `core_root:`.
- Message drift from the floor: a join on an over-approximated floored local widened a
  matched row's receiver (`for "s" | 1` against `for "s"`). Rows that read through such a
  join now decline (fixture 154). Empty seeds now decline too, rather than printing a bare
  `Array`.

Older port FPs the review found are filed as #482.

**Coverage cost:** the floor over-approximates, so 167 spec-fragment rows the reference
still fires go silent. On the real-world sweep it costs 0 rows: MATCHED equals the raw bump on
every corpus.

**Not ported:**
- ivar typing (#2384, #2375, #2486, #2469): the port does no ivar typing.
- `help --format=json` (reported as unsupported), editor mode, and `init`'s plugin suggestions.
- sig-gen coverage-only items.
- `core_root:` outside `check`.

**Result:** 0 FP, 9,441 files, 623 gaps, 159 fixtures. The three-way probe over 127 hand
targets found 0 port-only rows. Over the 1,223 spec fragments it found 0 `[XX.]` rows; the 5
`[X..]` rows left (`Set[..][0]`, refined `filter_map`) predate the bump.

## 4. Lessons

- A stale unit test can hide port FPs. `gate.sh` only tests crates the branch changed, so A's
  change broke a `rigor-cli` test that surfaced only after B touched that crate. Probing the
  test's rows against the oracle found 11 port-only rows.
- Recording a release's spec inputs as fragments (`tools/capture.rb`) turned a 909-commit
  changelog into a measurable 1,223-target set, and it made the coverage cost of an
  over-approximation countable.
